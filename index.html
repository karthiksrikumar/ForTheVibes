🔧 How It Works

The bookmarklet uses a smart insertion engine that mimics real keyboard input:

  • Native value setter — bypasses React/Vue's controlled input tracking, so it works on modern frameworks.
  • Input & Change events — fires real DOM events so the page believes a human is typing.
  • Human-like delays — 60% fast bursts, 25% normal pace, 10% slow, 5% thinking pauses.
  • Contenteditable support — works with rich text editors (Notion, Google Docs, etc.) using execCommand.
  • Click-to-stop — a global listener halts typing instantly if you click anywhere outside the target.
